⚠ This browser has no WebGPU. It will fall back to CPU (WebAssembly), which is very slow — expect minutes per bill. Use a recent Chrome or Edge on desktop for GPU speed.

⚠ Running on the integrated GPU. If this laptop also has an NVIDIA/AMD GPU, it will be several times faster. Browsers on Windows ignore a page's GPU request, so switch it in the browser:
  1. Open chrome://flags/#force-high-performance-gpu (Edge: edge://flags/#force-high-performance-gpu) and set it to Enabled.
  2. Or: Windows Settings → System → Display → Graphics → pick Chrome/Edge → Options → High performance.
  3. Fully quit the browser (all windows), reopen this page and load the model again. This badge should then show the discrete GPU.

⚠ This GPU reports small buffer limits. Use the Balanced resolution; High may fail with an out-of-memory error.
